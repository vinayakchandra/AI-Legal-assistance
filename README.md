# AI Legal Assistance

## Overview

`Streamlit` application that utilizes the `LangChain` library to create a chatbot for Indian law-related queries.

## Key Features

- Provides informative responses to user inquiries regarding Indian law
- Covers legal rights, processes, and relevant laws affecting individuals and businesses in India
- Utilizes the LangChain library and the `LLaMA` AI model

### Run the application:

   ```bash
   streamlit run main.py
